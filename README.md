
# Shotgun Metagenomic Analysis of Human Gut Microbiome

## Overview
Analysis of shotgun metagenomic sequencing data from a human gut microbiome sample using Kraken2 and R.

## Dataset
NCBI SRA accession: SRR32570884

## Tools Used
- FastQC
- Kraken2
- R
- ggplot2
- WSL (Ubuntu)

## Workflow
FASTQ → Quality Control → Taxonomic Classification → Visualization

## Key Findings
- Sample dominated by bacterial taxa
- Low viral abundance detected
- Presence of bacteriophage-associated viral reads
- Multiple phyla identified in gut microbiome
